# Civic-Sentinel

AI-powered risk intelligence platform for MPLADS project monitoring,
anomaly detection, and explainable alerts.

## 🚀 Smart India Hackathon Project

Civic-Sentinel was developed as a team project for the
Smart India Hackathon (SIH).
